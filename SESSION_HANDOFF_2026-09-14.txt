5. KEY CONVENTIONS WE ESTABLISHED
================================================================

- Money representation in engine: Long minor units.
  TND has 3 decimals, so 100.50 TND = 100_500L.
  Ivy persists money as Double — conversion happens only at the
  mapper boundary via CurrencyMinorUnits.

- Time conversion: Instant → LocalDate via ZoneId parameter.
  The zone is NEVER global. It is a function parameter everywhere.

- Allocation invariants (tested):
  Σ allocation amounts == source amount (exact)
  Allocation entries never create transactions
  Zero-amount days are omitted from the result

- Use case style:
  class Foo @Inject constructor(...) {
      suspend fun calculate(...) : X
  }
  or suspend operator fun invoke(...)

- Test style:
  JUnit4 + @RunWith(TestParameterInjector::class) + Kotest shouldBe
  Backtick test names. Real objects (no mocks) unless mocking a
  repository. coEvery/coVerify for suspend functions.

- Common LLM mistake to watch for: Gemini writes "not in" instead
  of "!in", "HALF_DOWN" instead of "HALF_UP", "verify" instead of
  "coVerify". Always compile and test each file.
