4. KEY ARCHITECTURAL FACTS
================================================================

Money:[cite: 5]
  - Engine + entities: Long minor units (1 TND = 1,000 millimes).[cite: 5]
  - Legacy Ivy: Double / BigDecimal.[cite: 5]
  - Conversions strictly at mapper boundary via CurrencyMinorUnits.[cite: 5]
  - NEVER Float, NEVER Double in new domain/money calculations.[cite: 5]

Time:[cite: 5]
  - Instant → LocalDate via explicit ZoneId parameters, never global UTC.[cite: 5]

Budget Pipeline:[cite: 5]
  RoomDynamicBudgetConfigStore → GetDynamicBudgetSnapshotUseCase
    → DynamicBudgetRepository → DynamicBudgetMapper →
    DynamicBudgetEngine → BudgetSnapshot → mapToSafeToSpendCardState
    → SafeToSpendCardState → SafeToSpendCard composable.[cite: 5]

Reactivity:[cite: 5]
  - TransactionRepository emits DataWriteEvent.SaveTransactions.[cite: 5]
  - HomeViewModel collects DataObserver.writeEvents via collectLatest
    and invokes reload().[cite: 5]
  - MutableSharedFlow buffered 16, DROP_OLDEST.[cite: 5]
  - LaunchedEffect(Unit) in uiState() handles initial paint.[cite: 5]
