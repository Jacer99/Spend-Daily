6. KEY ARCHITECTURAL FACTS[cite: 2]
================================================================

Money[cite: 2]:
  - Engine + new entities: Long minor units (TND = 3 decimals)[cite: 2]
  - Ivy legacy: Double / BigDecimal[cite: 2]
  - Conversion only at mapper boundary via CurrencyMinorUnits[cite: 2]
  - NEVER Float, NEVER Double in new money fields[cite: 2]

Time[cite: 2]:
  - Instant → LocalDate via ZoneId parameter, never global[cite: 2]

Budget pipeline[cite: 2]:
  RoomDynamicBudgetConfigStore → GetDynamicBudgetSnapshotUseCase
    → DynamicBudgetRepository → DynamicBudgetMapper →
    DynamicBudgetEngine → BudgetSnapshot → mapToSafeToSpendCardState
    → SafeToSpendCardState → SafeToSpendCard composable[cite: 2]

Reactivity[cite: 2]:
  - TransactionRepository posts DataWriteEvent.SaveTransactions[cite: 2]
  - HomeViewModel collects DataObserver.writeEvents via
    collectLatest and re-runs reload()[cite: 2]
  - MutableSharedFlow buffered 16, DROP_OLDEST[cite: 2]
  - LaunchedEffect(Unit) in uiState() handles first paint[cite: 2]
